EraMesh

EraMesh is a private mesh network for your own computers, phones and servers. You choose the order of exit devices, relays are always your own machines, and traffic moves to QUIC over TCP when a network blocks UDP.

Who it is for

People who run their own servers and want every device reachable from anywhere, with control over which machine their traffic leaves through and what happens when that machine goes down.

What works today

  • A Rust core and the fp command-line tool: SOCKS and HTTP proxy, application UDP, a tunneled DNS stub and static port forwards.
  • Devices join by invite, and members can take the exit or relay role.
  • An ordered list of exits. When an exit fails, traffic moves to the next one on the list, and an empty list blocks traffic instead of sending it out directly.
  • Member connections use TLS 1.3 with the hybrid post-quantum key exchange X25519MLKEM768 only. A peer that cannot use it fails the handshake.
  • A full-device tunnel on Linux.
  • Desktop, Android, iPhone and Apple TV apps that share one Rust core instead of reimplementing it.

Platform evidence

A platform counts as supported only after its app completes the shared acceptance flows on a recorded OS version. None has yet.

PlatformWhat has been shown

How it compares

Instead of EraMeshChoose it whenWhere EraMesh differs
Tailscale You want a private network that works today on every major platform. It is mature, and it is the better choice now. An ordered list of exits that fails closed, relays only through your own members, and QUIC carried over TCP when UDP is blocked.
Hysteria 2 You need one fast proxy from one client to one server. A network of member devices with invites, relays and exit failover. The project's lab runs both under the same network conditions, and that comparison is not finished.

Limits

  • No platform has passed full acceptance testing. The Windows build has never run on Windows.
  • The full-device tunnel stays off on macOS and Windows until leak prevention is in place.
  • When an exit fails, open TCP connections that went through it can reset. New connections use the next exit.
  • There is no release and no public source yet.
