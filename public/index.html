Era Suite

Infrastructure software for machines you own: a private network for your devices, an application database that reads from the device first, and a CI fleet for GitHub Actions.

The three projects are at different stages. Each page says what works today, what does not, and when another tool is the better choice.

About these pages

Era Suite is a family of projects by Zhendi Fan. Every claim on these pages comes from the project's own README and test records. Each page names the tools you may already use, says where they are better, and lists the project's limits before you run into them.

EraInfra's source is on GitHub. EraDB and EraMesh will link to their source when it is public.
