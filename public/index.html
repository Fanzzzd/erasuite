Era Suite

Developer infrastructure that runs on machines you own: an application database, a CI fleet, and a private network for your devices.

The three projects are at different stages. Each page says what works today, what does not, and how it compares with tools you may already use.

  1. EraMesh A private network for your own devices. It picks a direct, relayed or TCP path and sends traffic out through the exit you choose. In development. Not released.
  2. EraDB A local-first TypeScript application database. Apps read from local storage while PostgreSQL stays the source of truth. Release candidate 0.1.0-rc.1. Not on npm yet.
  3. EraInfra Self-hosted GitHub Actions runners on your own Linux, Mac and Windows machines. Each job gets a fresh VM, and no machine needs a public IP. Source on GitHub under the MIT license.

Era Suite is built by Zhendi Fan. EraInfra source is on GitHub under the MIT license.
