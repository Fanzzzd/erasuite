EraDB

EraDB is a local-first TypeScript application database. Your app reads from durable local storage and shows the predicted result of a command immediately. PostgreSQL stays the authority, and every query result says whether the local data is complete.

Who it is for

App developers who want a typed, realtime backend in the style of Convex, running on their own PostgreSQL instead of a hosted service.

How it compares

  • Convex is the model EraDB follows, and it is hosted and in production use today. EraDB scores itself against every Convex capability, and that check currently fails.
  • PostgreSQL with your own API leaves sync, local caching and optimistic updates to you. EraDB includes them, with ordered WebSocket sync and policy checks on the server.

What it includes

  • A typed schema, query and command core with a build-time command compiler.
  • A durable browser Worker and local client, with React and other framework bindings and native clients.
  • PostgreSQL execution, server functions, scheduling, file storage, search and auth.
  • A CLI, a dashboard and a self-host control plane.

Limits

  • Release candidate 0.1.0-rc.1. Its 22 packages build as local tarballs and none is published to npm.
  • Self-hosting works with a locally built control-plane image and PostgreSQL. There is no hosted service.
  • The source is not public yet.

Get it

EraDB is not available for download yet. This page will link to the source and packages when they are published.
